# Animacje 3D

Interaktywne animacje 3D dla stron firmowych. Strona: https://tomaszkowallike-prog.github.io/animacje-3d/

| Zakładka | Dla domeny |
|---|---|
| Ocieplenie elewacji | wi-bud.pl |
| Dom bunkier | brickon.pl |
| Tablica domen | domena.pl |
| Rejestracja domen (makieta) | domena.pl |
| Zegarek — teardown | demo techniczne |

Każda animacja to jeden plik HTML w folderze `animacje/`, bez plików modeli i obrazków.
